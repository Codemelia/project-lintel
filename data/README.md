# `data/` — Curated knowledge base

Place `services.json` here: **eight** Singapore providers (SOS, IMH Emergency, national mindline, CHAT, polyclinics, FSCs, CREST, private counselling) with age, cost, urgency, and access-pathway fields.

See [indexed providers](../docs/project-plan.md#33-indexed-providers) and [root README knowledge base](../README.md#knowledge-base). Do not treat this file as a live clinical directory; verify contacts against the [MOH mental health services page](https://www.moh.gov.sg/seeking-healthcare/find-a-facility-or-service/mental-health-services/) before freeze.
